## Data contract draft

Per source sample: sample_id, garment_id/specimen_id, source_id, source_url or local capture ID, terms reference, content hash, capture-session ID, camera configuration, label values, label evidence, label-review state, split, and any parent image ID.

Per prediction: frame_id, monotonic capture time, inference start/end, model bundle ID, calibration ID, camera-config ID, region coordinates, valid-frame state, each attribute label/score/abstention reason, and result age. Fabric crops inherit their frame and garment IDs.

Per recorded evaluation: include ground truth separately from predictions; never use model output as its own ground truth. Human corrections are versioned labels rather than silent overwrites.
